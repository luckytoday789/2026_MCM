# SafeInvest 独立核查清单

以下项目需结合具体版本逐项提供证据。当前除原题与题意 README 对照外，尚未开展主程序或数值结果核查。

## A. 数据与信息边界

- [ ] 原始数据不被改写，记录所用输入文件及版本或哈希。
- [ ] 情景与年度唯一，缺失值、排序和收益率单位正确。
- [ ] 不将不同情景连接成一条时间序列，不将情景内未来年份用于当年决策。
- [ ] 情景 1–120 用于开发，121–180 在最终策略冻结后评估。
- [ ] 统计估计、标准化、阈值选择等步骤不使用最终测试数据拟合。
- [ ] 改动第 t 期及以后观测，不应改变该情景第 t 期及此前的决策；核查时使用合成或开发集副本。

## B. 财富和交易账本

- [ ] 初始 100 单位全部为票据，无后续注资或提款；高流动性需求不被擅自转化为提款。
- [ ] 持仓非负，无杠杆，扣费后所有财富分配于三类资产。
- [ ] 费用为转移金额的 0.25%，同一转移只计一次；20 单位单向转移费用为 0.05。
- [ ] 初始配置也收费，费用在当期收益发生前扣除。
- [ ] 明确费用从何处支付、转移金额如何定义、目标权重在扣费前还是扣费后成立，并与实现一致。
- [ ] 不误用买卖总额双边收费；不忽略目标权重、费额和交易后财富之间的关系。
- [ ] 逐期满足交易前财富 = 交易后财富 + 费用；年末财富与各资产收益独立复算一致。
- [ ] 零收益、零费用、无交易、单资产及配置已经等于目标等边界正确。
- [ ] 忽略题目要求忽略的税、其他费用及终值清算费用。

## C. 基准、指标与实验比较

- [ ] 基准每期恢复三类资产各三分之一，目标始终固定，费用口径与策略相同。
- [ ] 实际收益使用 `(1 + 名义收益) / (1 + 通胀) - 1`，不简单相减替代精确关系。
- [ ] 实际财富使用从本情景开始累计的物价指数，单位和初始值一致。
- [ ] 明确普通波动与严重损失的不同指标，严重损失数值越大表示越差。
- [ ] 若用最大回撤，明确年度观察与交易时点的采样口径，峰值计算包括初始财富。
- [ ] 先计算每个情景的增长及损失，再在情景之间计算中位数与分位数。
- [ ] 报告增长中位数、严重损失中位数、增长第 10 百分位、严重损失第 90 百分位。
- [ ] 相同情景、期限及费用下比较，并区分配置变化、再平衡变化与动态目标变化的贡献。
- [ ] 交易占比明确分母和初始建仓是否计入；不能用“检查次数”代替“实际交易次数”。
- [ ] 严重情景的选择规则透明，案例不被用作事后调参依据。

## D. 决策与客户适配

- [ ] 对保持、再平衡、改变目标及人工审核均有可执行定义。
- [ ] 每次交易有事前收益与成本的判断；仅设置偏离阈值不足以证明费用合理。
- [ ] 明确风险调整分数与预期金钱收益的区别，不把估计优势写成保证。
- [ ] 客户 A–E 分别按 5、15、30、25、6 年评估。
- [ ] 客户损失容忍度不被解释成组合损失保证；票据不被解释为实际购买力无风险。
- [ ] 流动性约束、可接受超限频率等新增假设显式披露，不伪称题目规定。
- [ ] 所有客户均有推荐结果或明确的人工审核结论。
- [ ] 审核触发仅用当时已知信息，等待期间的组合动作明确且已经纳入回测。

## E. 可靠性、报告和复现

- [ ] 至少检验一个重要假设或交易费率，说明主要建议是否改变。
- [ ] 识别重要局限、自动化暂停条件及等待审核的风险。
- [ ] 明确是否建议自动目标更新，结论与实验支持程度一致。
- [ ] 图表、正文、汇总表与逐情景结果使用同一版本。
- [ ] 客户解释不超过 50 个英文单词，无收益保证。
- [ ] 英文报告不超过 10 页 A4，字号不小于 11pt，列出所有成员。
- [ ] AI 使用及用途被披露，参考文献可核实，数据来源与许可得到适当说明。
- [ ] 代码入口可运行，所需文件齐全，补充 ZIP 不超过 50MB。
